# Return to work

## 1. Timeline model
Build a table in `campaign/STATE.md › Key dates`:

| Date | Event |
|---|---|
| T_end | Leave ends / availability date |
| T_end − n weeks | Start active applications (n ≈ typical hiring cycle in the target market: ask, default 8–10 weeks) |
| T_offer | Target offer date |
| T_offer + notice | Earliest start at the new employer |

If the owner is currently employed, the **notice period** of the current contract drives
the earliest start. Ask what their contract / local law says. For reference only (verify
before acting): under the Polish Labour Code (art. 36 KP) notice for an indefinite-term
contract is 2 weeks (< 6 months' tenure), 1 month (6 months – 3 years), 3 months (≥ 3 years),
and parties can agree to end earlier by mutual agreement (*porozumienie stron*).
Leave-related protections and rights differ by country and change over time — recommend
the owner confirms specifics with HR or a labour lawyer; you are not giving legal advice.

## 2. Framing the gap
- **CV:** a single line in the timeline is enough, e.g. "Parental leave" with dates — or
  nothing, if the owner remained employed (leave doesn't end the employment). Owner chooses.
- **Interview line (draft with the owner, store in `positioning.md`):** one confident
  sentence + a pivot to what they're ready to do now. No apologies, no over-explaining.
- **Refresh signals:** courses, certifications, reading, volunteering done during the
  break can go in the CV if the owner wants — never invented.

## 3. Constraints honesty
If the owner has new constraints (hours, remote days, commute), record them in
`positioning.md › Constraints` and let triage enforce them. Don't help hide constraints
that will surface in the job anyway — help find roles that fit them.

## 4. Questions the agent should *not* ask
Don't probe family plans, health or childcare arrangements. Only use what the owner volunteers.
